# 실버 말하기 시제품 (0단계)

말 → 글 → 대답 → 말 왕복을 안드로이드 폰에서 확인하기 위한 최소 화면입니다. 설치 없이 Chrome에서 열리고, "홈 화면에 추가"로 앱처럼 쓸 수 있습니다. 1단계의 진짜 앱(Play 스토어 배포)과는 별개이며, 0단계 측정용입니다.

## 파일

- `index.html` 화면 전체(큰 버튼, 큰 글씨, 음성 인식·합성, 왕복 시간표, 지도 딥링크 테스트)
- `server.js` 대화 서버(선택). Claude 연결 시 `npm install @anthropic-ai/sdk` 뒤 `node server.js`
- `manifest.webmanifest`, `sw.js`, `icon.svg` 홈 화면 설치용

## PC에서 열기

```
cd 시제품
python -m http.server 8787 --bind 127.0.0.1
```
브라우저에서 http://localhost:8787 접속. 마이크 권한을 허용하고 "눌러서 말하기".

## 폰에서 열기 (중요)

마이크는 **https 또는 localhost에서만** 켜집니다. PC의 LAN 주소(http://192.168.x.x:8787)로 열면 인식이 시작되지 않습니다. 방법은 둘 중 하나:

1. GitHub Pages 같은 https 호스팅에 `시제품/` 폴더를 올린다(공개 저장소 → 대표 승인 필요).
2. PC에서 임시 https 터널을 연다(예: `npx localtunnel --port 8787`). 외부에 PC 포트가 열리므로 테스트 동안만.

## 보는 법

- 화면 아래 "진단 정보"에 음성 인식 가능 여부(ko-KR, 기기 내 처리 여부), 한국어 목소리 목록이 나옵니다.
- 왕복 한 번마다 표에 ms 단위로 기록됩니다. 목표: 버튼 → 읽기 시작까지 2초 안.
- "길 안내 열기"의 세 버튼은 각각 네이버 지도·카카오맵·기본 지도 앱이 대중교통 길찾기로 열리는지 확인합니다.
